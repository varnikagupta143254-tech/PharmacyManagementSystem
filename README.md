Pharmacy Management System

A web application to manage pharmacy medicine inventory. After logging in, a user can add, view, edit and delete medicines.

Built for the Advanced Java Technologies (01CE0308) course, Marwadi University.
 
Login: admin / admin123

Features
Login and logout using sessions
Servlet filter that protects all pages
Add, view, edit and delete medicines
Client-side and server-side form validation
Technologies

Java Servlets, JSP/JSTL, JDBC, MySQL, Maven, Apache Tomcat 9

Run Locally
Start MySQL in XAMPP.
In phpMyAdmin, run the schema.sql file to create the database.
Open the project in NetBeans and run it on Tomcat 9.
Open http://localhost:8080/PharmacyManagementSystem/ and log in with admin / admin123.
